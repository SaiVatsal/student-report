# Project 36: Academic Gradebook & Student Progress System (Aegis Scholar)

An academic transcript, faculty gradebook, and student performance portal built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **Soft Pastel-Blue Theme**: Academic institution aesthetic (`#f0f9ff`, `#0284c7`, `#0369a1`) with Plus Jakarta Sans and JetBrains Mono typography.
- **Faculty Gradebook Matrix**: Real-time marks entry with instant weighted GPA calculation and class percentile rankings.
- **Parent/Student Analytics Portal**: Subject mastery progress bars, verified attendance records, and term performance radar metrics.
- **Official Academic Report-Card**: Print-ready transcript with course codes, letter grades, dean signature lines, and institutional accreditation seals.

## Getting Started
```bash
npm install
npm run dev
```
